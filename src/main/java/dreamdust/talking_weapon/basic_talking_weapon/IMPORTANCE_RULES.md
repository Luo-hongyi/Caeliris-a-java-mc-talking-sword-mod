# 基础重要度规则说明 (Base Importance Rules)

本文档记录了 Talking Weapon Mod 中各个感知采集器（Collector）向 Agent 上下文注入 `TaggedContextEntry` 时所赋予的“客观基础重要度 (`baseImportance`)” 分配规则。

> **注意：** 最终发送给 LLM 的 `finalImportance` 会再乘以配置文件中的 **注意力权重（Attention Weights）**。

## 1. 玩家基础状态 (`BaseContextCollector`)

| 标签 (FocusTag) | 触发条件 / 描述 | 基础重要度 | 备注 |
| :--- | :--- | :---: | :--- |
| `STATUS` | 玩家生命值 < 10% (极度危险) | **`1.0`** | 强制引起最高关注 |
| `STATUS` | 玩家生命值 < 30% (低血量状态) | **`0.7`** | |
| `STATUS` | 玩家生命值 < 80% (中等健康) | **`0.2`** | 关注度较低 |
| `STATUS` | 玩家生命值 ≥ 80% (健康满血) | **`0.1`** | |
| `LANDSCAPE` | 当前时间 (如清晨、中午、深夜等) | **`0.2`** | 常规背景信息 |
| `LANDSCAPE` | 当前天气：雷暴风雨 (`isThundering`) | **`0.5`** | |
| `LANDSCAPE` | 当前天气：下雨 (`isRaining`) | **`0.3`** | |
| `LANDSCAPE` | 当前天气：晴天 / 无特殊天气 | **`0.1`** | |
| `LANDSCAPE` | 当前所处生态群系 | **`0.3`** | 常规背景信息 |

## 2. 玩家环境细节 (`PlayerEnvironmentCollector`)

| 标签 (FocusTag) | 触发条件 / 描述 | 基础重要度 | 备注 |
| :--- | :--- | :---: | :--- |
| `LANDSCAPE` | 当前所处维度 (主世界/下界/末地) | **`0.3`** | |
| `HAZARD` | 脚下有效光照强度 < 7 (过暗，可能刷怪) | **`0.5`** | 切换为危险关注 |
| `LANDSCAPE` | 脚下有效光照强度 ≥ 7 (明亮安全) | **`0.1`** | 恢复为环境关注 |
| `TOOL` | 玩家当前主手正拿着的物品 | **`0.2`** | |

## 3. 近期动作流 (`RecentActionCollector`)

| 标签 (FocusTag) | 触发条件 / 描述 | 基础重要度 | 备注 |
| :--- | :--- | :---: | :--- |
| (动态匹配事件) | Agent 获取到当前缓存窗口内的动作总结 | **`0.8`** | 反映玩家当下的具体行动意图，优先级非常高 |

## 4. 附近实体雷达 (`NearbyEntitiesCollector`)

实体的重要度主要基于玩家距离动态衰减，并带有对高威胁目标的特殊覆写规则。

| 实体分类 | 距离 (d) 判定 | 基础重要度 | 备注 |
| :--- | :--- | :---: | :--- |
| **首领/玩家级目标** | 任何距离 | **`0.9`** | 如果扫描到的是 **BOSS** (BossEvent) 或 **其他玩家** (Player)，无视距离直接强制最高关注度 |
| 其它一般实体 | d < 5 格 | **`0.8`** | 贴脸/近战范围 |
| 其它一般实体 | d < 15 格 | **`0.5`** | 弓箭射击范围 |
| 其它一般实体 | d < 30 格 | **`0.3`** | 中远警戒距离 |
| 其它一般实体 | d ≥ 30 格 | **`0.1`** | 远距离背景实体 |

## 其他说明
*   部分采集器（例如 `LookingAtCollector` 准星注视、`NearbyStructureCollector` 建筑探查 等）目前多以填充 `Context.extras` 文本字典为主，本身不会显式声明单条 `TaggedContextEntry` 以及计算分数，LLM 会将当作附加信息或隐性上下文理解。
*   后续如需实现绑定 Agent 性格的基础算法迭代，可以继续扩充和打乱此文件的逻辑。
